    LEARN
    How Contract Downloader works
    A practical guide to prepare inputs, download attachments, and recover safely from errors.
    
                
    
                    
    01
    Prepare the input
    Use an Excel or CSV file with PO_NUMBER and SUPPLIER. The template includes an <|> separator. Save and close Excel before validating.
    Columns after <|> become folder levels. Blank required fields are reported before any download starts.
    
                    
    02
    Follow the journey
    The New Run journey has three stages: input, validation, and final folder setup. A run starts only after you approve the visible folder tree.
    Completed steps remain available for navigation; the final stage combines the save location, hierarchy, and approval.
    
                    
    03
    What happens during a run?
    The app uses authenticated HTTP requests to Coupa, reads PO and PR pages, discovers attachments, and saves them inside the run folder.
    The official HTTP engine uses 11 concurrent downloads with adaptive backoff when Coupa responds with rate limits.
    
                    
    04
    Errors and retries
    Open Active run for progress and logs. Automatic retries can be configured in Settings, and failed POs can also be retried manually from History.
    A retry uses the same run folder and preserves valid existing files.
    
                    
    05
    History and reports
    Run history stores PO-level results, retry history, preserved inputs, reports, and links back to Coupa. You can delete one run or clear all history.
    Deleting a run removes its run folder; original input files outside that folder are preserved.
    
                    
    06
    Authentication and privacy
    Authentication reuses the existing Microsoft Edge work profile and secure native session storage until Coupa invalidates it. Close all Edge windows only when the app asks.
    The app does not send telemetry. Cookies, credentials, and input documents stay on the local machine.
    
                
    
            
    

            
    
                
    SETTINGS
    Preferences
    Control downloads, retries, updates, and how long runs remain in history.
    
                
    
                    
    
                        
                        
                        
                        
                        
                    
    
                    
    
                        
    Language
    Changes the application interface language. CLI output and logs remain in English.
    
                        
    Text size
    Adjusts the interface scale for readability. The preview is applied immediately and saved on this computer.
    
                    
    
                    
    
                        
    Downloads
    Choose the base folder. Each run receives its own timestamped subfolder.
    
                        
    Downloads simultaneous
    How many POs the app processes at the same time. Higher values may increase server load.
    Estimate for 100 POs will be calculated from completed runs.
    
                        
    Retry policy
    Automatic attempts for a PO before marking it as failed. Manual retry remains available from History.
    
                        
    Email files (.msg)
    Choose whether downloaded email files are converted to PDF and whether their real attachments are extracted.
    
                        
    Duplicate files
    Compare files with SHA-256. Identical files use a hard link when possible, or a reference sidecar when they are on different volumes.
    
                    
    
                    
    
                        
    Updates
    Startup checks are optional. You can always check, download, verify, and install an update manually.
    
                    
    
                    
    
                        
    Contract Downloader browser
    Choose the browser used by Contract Downloader for Coupa sign-in. External links continue to use your operating system default browser.
    
                        
    Coupa sign-in
    The app uses a separate persistent profile for sign-in, so personal browser windows and profiles are not changed or locked.
    
                    
    
                    
    
                        
    NGSI supplier master data
    Search all supplier hierarchy levels (SU, GU and UU), then save an alias to the associated UU group. New runs use these mappings as their local NGSI supplier cache.
    Search the Power BI dataset to find a supplier group.

    Start clean
    Forget local run history and sign-in state while preserving downloaded files, reports, and original inputs. Close the app sign-in browser and stop any active run first.
    
                        
    History retention
    Automatic cleanup only applies to completed runs and never removes an active run.
