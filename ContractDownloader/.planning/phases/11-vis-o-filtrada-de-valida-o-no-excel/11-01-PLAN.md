# Plan 11-01: abrir cópia filtrada no Excel

## Backend

1. Construir uma visão temporária a partir do resultado atual de `validate_input_file`.
2. Marcar cada linha de origem com status e categorias de erro/aviso.
3. Preservar conteúdo, ordem e número de linha original; suportar CSV, XLSX e XLSM.
4. Configurar AutoFilter na cópia para exibir apenas problemas e abrir o arquivo nativamente.
5. Retornar caminho, contagens e mensagem sem tocar no arquivo original.

## GUI

1. Adicionar ação `Open filtered view in Excel` na tela de validação quando houver problemas.
2. Informar que é uma cópia de trabalho e que o original não foi alterado.
3. Reutilizar mensagens pt-BR/English e reportar falhas de geração/abertura.

## Testes

- Cópia mantém todas as linhas/colunas do CSV/XLSX.
- Filtro marca somente linhas afetadas.
- Arquivo original permanece byte a byte inalterado.
- Números de linha, POs e categorias são preservados.
- API e JavaScript compilam e suíte completa passa.
